# Nibiru India first-build pilot

This folder contains a small, repeatable community pilot for helping developers
complete their first verifiable action on Nibiru Testnet 2. It is designed for
an online room or a 20–40 person local session in India.

## Current status

**Prepared, not yet delivered.** The materials are public so facilitators and
Nibiru community members can review them before anyone is invited. Attendance,
transactions, repositories, and feedback will be reported only after they
exist.

## What success means

A participant should leave with one of these outcomes:

- a correctly configured Testnet 2 wallet;
- a confirmed public transaction and an understanding of its receipt;
- a small public repository with build notes; or
- a clearly documented blocker that can become useful community feedback.

Registration count is context, not the primary result. The pilot measures
completed actions, recurring blockers, seven-day follow-up, and people who are
ready to help the next participant.

## Pilot materials

- [`FIRST_SESSION.md`](FIRST_SESSION.md) — 60-minute workshop plan and room roles.
- [`HINDI_QUICKSTART.md`](HINDI_QUICKSTART.md) — bilingual safety and setup guide.
- [`CONTENT_SPRINT.md`](CONTENT_SPRINT.md) — seven days of useful, non-spam content.
- [`COMMUNITY_CARE.md`](COMMUNITY_CARE.md) — moderation and member-recognition rules.
- [`templates/session_metrics.csv`](templates/session_metrics.csv) — empty outcome tracker.
- [`templates/participant_followup.md`](templates/participant_followup.md) — 48-hour follow-up message.
- [`templates/retrospective.md`](templates/retrospective.md) — transparent post-session report.
- [`PUBLIC_BETA_CHECKLIST.md`](PUBLIC_BETA_CHECKLIST.md) — safe execution path from rehearsal to a public case study.

The live Debug Desk also includes a browser-only Pilot Evidence tracker. It
validates aggregate counts and exports the same results as Markdown or CSV
without submitting participant information to a server.

## Operating principle

No wallet secrets, no investment advice, no purchased engagement, and no
inflated numbers. This is an independent community experiment and must not be
presented as an official Nibiru program without written approval.
