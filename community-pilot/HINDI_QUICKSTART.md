# Nibiru Testnet 2: English + Hindi quick start

This handout is intentionally short. Always verify network details against the
[official Nibiru documentation](https://nibiru.fi/docs/dev/networks) before a
session.

## 1. Safety / सुरक्षा

**English:** Use Testnet 2 only. Never share a seed phrase or private key with a
website, form, organizer, mentor, or support account. Testnet tokens have no
monetary value.

**हिंदी:** केवल Testnet 2 का उपयोग करें। अपनी seed phrase या private key किसी
website, form, organizer, mentor या support account के साथ कभी साझा न करें।
Testnet token की कोई वास्तविक आर्थिक कीमत नहीं होती।

## 2. Verify the network / नेटवर्क जाँचें

| Field | Expected value |
|---|---|
| Network | Nibiru Testnet 2 |
| EVM chain ID | `6911` |
| Hex chain ID | `0x1AFF` |
| Currency symbol | `NIBI` |

**English:** Do not trust a copied configuration only because it came from a
chat message. Compare it with the current official network page.

**हिंदी:** किसी chat message से मिली network setting पर सीधे भरोसा न करें। उसे
official network page की वर्तमान जानकारी से मिलाएँ।

## 3. Read a public transaction / पब्लिक ट्रांज़ैक्शन समझें

A public transaction hash can be checked safely. Look for:

- whether the transaction was found;
- pending, successful, or reverted status;
- block number and confirmations;
- sender and destination addresses; and
- gas used and transaction cost on testnet.

Public address और transaction hash जाँच के लिए साझा किए जा सकते हैं। Seed
phrase और private key कभी साझा नहीं करनी है।

## 4. Ask for help well / सही तरीके से सहायता माँगें

Include the network, public hash, time, exact error, expected result, observed
result, and reproduction steps. Remove personal information and secrets before
posting.

सहायता माँगते समय network, public hash, समय, error, expected result और steps
लिखें। पोस्ट करने से पहले निजी जानकारी और secrets हटा दें।

Use [Nibiru Debug Desk](https://nibiru-community-launchpad.arunchandel1780.workers.dev/)
to prepare a sanitized Markdown report.
