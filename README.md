# Nibiru Community Launchpad

An independent, testnet-first onboarding product for helping new builders move from curiosity to a verifiable first action on Nibiru.

This is not a brochure site. It combines a live Nibiru Testnet 2 health check, a saved builder checklist, transaction verification, and a repeatable workshop system for community leads.

## What a participant can do

- Confirm that Nibiru Testnet 2 is responding and see its latest block.
- Copy the current RPC, EVM chain ID, and currency symbol.
- Follow a five-step builder journey with progress saved in the browser.
- Verify a testnet transaction directly against the network.
- Understand what a complete community workshop should produce.

## Community operating model

The pilot is designed for a curated group of 25–40 builders in Indore, India. The workshop measures completed wallet setups, verified transactions, public build proofs, and 30-day contributor retention instead of relying on attendance alone.

The next stage repeats the improved curriculum in Bhopal, then publishes a lightweight city playbook for trusted organizers.

## Safety and attribution

This is an independent proof of work by [Arun Chandel](https://github.com/Arun5768). It is not affiliated with or endorsed by Nibiru.

- Never enter a seed phrase or private key.
- Use testnet accounts only.
- Testnet tokens have no monetary value.
- Network details link back to the [official Nibiru documentation](https://nibiru.fi/docs/dev/networks).
