# Contribution map

This project is an independent community contribution. The goal is to turn workshop friction into useful, upstream-ready feedback—not to imply official status.

## Before opening anything upstream

1. Reproduce the issue against the latest official documentation or repository state.
2. Remove wallet identifiers, screenshots containing personal data, and venue information.
3. Write the smallest reproducible example.
4. Search existing issues and discussions.
5. Follow the target repository’s contribution and security guidance.

## Useful official destinations

- [Nibiru Developer Hub](https://nibiru.fi/docs/dev) for the current developer path.
- [NibiruChain repositories](https://github.com/NibiruChain) for source, issues, and repository-specific contribution rules.
- [Nibiru EVM documentation](https://nibiru.fi/docs/dev/evm) for Solidity and JSON-RPC onboarding.
- [Nibiru Testnet explorer](https://testnet.nibiscan.io) for verifying public transactions.
